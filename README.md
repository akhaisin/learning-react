# React exercises

Various React exercises which fit into 1h maximum interview session.

## Stack and Commands
- Stack: React + TypeScript + Vite
- Package manager: pnpm
- Common commands:
  - `pnpm dev`
  - `pnpm build`
  - `pnpm lint`
  - `pnpm test:run`
